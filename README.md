# Neon Survivor — Édition Complète

Jeu de survie néon navigateur (campagne, infini, daily, boss rush).

## Modes

| Mode | Description |
|------|-------------|
| **Campagne** | 15 mondes × 20 étapes + boss uniques |
| **Mode Infini** | Vagues sans fin |
| **Défi du jour** | Étape unique quotidienne, 1× / jour |
| **Boss Rush** | Enchaîne les 15 boss (débloqué après monde 3) |

## Contenu

- **50 personnages** (30 handcrafted + 20 uniques Option C)
- **12 reliques** (3 emplacements)
- **15 mondes** avec physiques différentes
- **15 boss** uniques
- Musique Web Audio (volume réglable)
- PWA installable + offline
- Multilingue, sauvegarde locale, succès

## Options A→D

- **A** : PWA, loader, mobile, pools
- **B** : pooling, volume SFX, écran options
- **C** : personnages uniques + reliques
- **D** : équilibrage, daily, 5 nouveaux mondes, boss rush, musique volume

## Lancer

```bash
cd neon-survivor
npx serve .
```
